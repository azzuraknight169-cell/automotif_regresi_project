[TAMPILKAN README.md]

Di README.md dijelaskan tujuan proyek, sumber dataset, cara menjalankan program, dan struktur berkas. Dataset yang digunakan bernama mpg.csv, yang berisi 234 observasi mobil dan 11 kolom. Pada proyek ini saya berfokus pada dua kolom, yaitu displ sebagai kapasitas mesin dalam liter dan hwy sebagai efisiensi bahan bakar di jalan raya dalam satuan miles per gallon atau MPG. Dataset bersumber dari dokumentasi mpg pada plotnine dan ggplot2.

[TAMPILKAN mpg.csv, lalu validasi_dataset.ipynb]

Sebelum membuat model, data diperiksa terlebih dahulu. Notebook validasi_dataset.ipynb membaca dataset menggunakan Pandas, menampilkan lima baris pertama dan nama kolom, memeriksa nilai kosong pada variabel yang digunakan, serta menampilkan statistik ringkas. Notebook ini juga membuat scatter plot untuk melihat pola hubungan antara kapasitas mesin dan efisiensi bahan bakar.

[TAMPILKAN analisis_regresi_linear.ipynb]

Berikutnya, notebook analisis_regresi_linear.ipynb berisi proses analisis dan pelatihan model. Data yang dipakai adalah kolom displ sebagai variabel independen atau X, dan hwy sebagai variabel dependen atau target y. Data kemudian dibagi menjadi data latih dan data uji dengan rasio 80 banding 20. Pembagian menggunakan random_state 42 agar dapat direproduksi.

Model dilatih menggunakan LinearRegression dari Scikit-learn. Setelah itu, hasil prediksi dibandingkan dengan nilai aktual dan dievaluasi menggunakan R-squared, Mean Absolute Error, serta Root Mean Squared Error. Notebook juga menampilkan grafik perbandingan nilai MPG aktual dan prediksi, lalu menyimpan model menggunakan Joblib.

[TAMPILKAN train_model.py]

Proses pelatihan yang sama dibuat kembali dalam bentuk script Python bernama train_model.py supaya bisa dijalankan dari terminal atau server deployment. Script ini membaca mpg.csv, memeriksa kolom yang diperlukan, menghapus baris yang memiliki nilai kosong pada dua kolom terpilih, membagi data, melatih model, menghitung metrik evaluasi, dan menyimpan model ke model.joblib. Nilai evaluasi juga disimpan di model_metrics.json.

Berdasarkan hasil yang tercatat pada proyek ini, persamaan regresinya adalah hwy sama dengan 36,162 dikurangi 3,653 dikalikan displ. Koefisien negatif menunjukkan bahwa pada dataset ini, kapasitas mesin yang lebih besar cenderung berhubungan dengan efisiensi bahan bakar jalan raya yang lebih rendah. Nilai R-squared sekitar 0,528, MAE sekitar 2,484 MPG, dan RMSE sekitar 3,539 MPG.

Artinya, model memberikan perkiraan yang cukup informatif, tetapi prediksinya tetap memiliki kesalahan. Model hanya menggunakan kapasitas mesin dan belum mempertimbangkan faktor lain seperti bobot mobil, jumlah silinder, transmisi, dan jenis kendaraan. Karena itu, hasilnya merupakan estimasi edukatif dan bukan jaminan konsumsi bahan bakar aktual atau bukti bahwa kapasitas mesin adalah satu-satunya penyebab perubahan efisiensi.

[TAMPILKAN model_metrics.json dan model.joblib]

File model_metrics.json berisi ringkasan ukuran dataset, jumlah data latih dan uji, nilai intersep dan koefisien, serta metrik evaluasi. Sementara itu, model.joblib adalah file model terlatih yang dimuat kembali oleh aplikasi agar aplikasi tidak perlu melatih model setiap kali menerima input. Model ini juga dapat dibuat ulang dengan menjalankan train_model.py.

[TAMPILKAN app.py]

File app.py merupakan backend aplikasi web berbasis Flask. Saat aplikasi dimulai, program memuat model.joblib. Ketika pengguna mengirimkan kapasitas mesin, backend memeriksa apakah input berupa angka dan berada dalam rentang 1,6 sampai 7 liter. Jika input valid, model menghasilkan estimasi MPG. Jika input tidak valid, aplikasi menampilkan pesan kesalahan.

[TAMPILKAN templates/index.html]

File index.html merupakan tampilan halaman web. Di dalamnya terdapat judul aplikasi, kolom untuk memasukkan kapasitas mesin dalam liter, tombol prediksi, area untuk menampilkan hasil, dan penjelasan singkat tentang model serta keterbatasannya. Tampilan ini menggunakan Bootstrap agar susunannya lebih rapi dan responsif.

[TAMPILKAN requirements.txt DAN Procfile]

File requirements.txt mencantumkan pustaka yang diperlukan, seperti Flask, Pandas, Scikit-learn, NumPy, Matplotlib, Joblib, dan Gunicorn. File Procfile berisi perintah untuk menjalankan aplikasi menggunakan Gunicorn pada port yang disediakan oleh platform hosting. File-file ini diperlukan agar proyek lebih mudah dijalankan dan dipublikasikan sebagai aplikasi web.

[TAMPILKAN scatter_regresi.png dan aktual_vs_prediksi.png jika diperlukan]

Selain kode, paket juga berisi grafik untuk membantu membaca hubungan kapasitas mesin dengan MPG serta membandingkan nilai aktual dan nilai prediksi. Di dalam paket terdapat pula laporan tugas pendahuluan dan tugas akhir sebagai dokumentasi proyek.
